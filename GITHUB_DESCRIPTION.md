## Suggested release title

`WSJTX-HackRF v0.1.0 — Initial HackRF public release`

## Suggested release summary

WSJTX-HackRF v0.1.0 is the first public HackRF-focused release. It builds a private WSJT-X 3.0.2 environment together with Hamlib 4.5.5, libhackrf 2021.03.1 and the WSJTX-HackRF bridge. The release includes native HackRF RX/TX gain controls, persistent gain settings, bridge/USB diagnostics, ADIF export improvements and REG1TEST EDI export. The HackRF bridge is disabled by default and must be explicitly enabled by the user. The complete public build has been validated end-to-end on Ubuntu 20.04. PlutoSDR and Ettus/USRP support are deferred to a future release.
